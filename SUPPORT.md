# Support

- **Using the app** (an account, a device, a contact): the
  [support page](https://hqchat.app/support).
- **A bug or a feature request**: an issue on
  [HQCHAT](https://github.com/HQChat/HQCHAT/issues/new/choose).
- **A vulnerability**: privately, as described in [SECURITY.md](SECURITY.md).
