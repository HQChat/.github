# Security policy

Report a vulnerability privately through a security advisory on the affected
repository (for the apps, the server and the infrastructure, that is
[HQCHAT](https://github.com/HQChat/HQCHAT/security/advisories/new)). Do not
open a public issue. If an advisory is not possible, use the contact address on
the [support page](https://hqchat.app/support).

Say what you can reproduce and how. A proof of concept is welcome but not
required. We aim to acknowledge within a few days. There is no bounty
programme and no legal threat: research reported in good faith is welcome.

Scope and what counts as serious are set out in
[HQCHAT's security policy](https://github.com/HQChat/HQCHAT/blob/main/SECURITY.md).
