# Contributing

Each repository's own `CONTRIBUTING.md` takes precedence. For the main one, read
[HQCHAT's](https://github.com/HQChat/HQCHAT/blob/main/CONTRIBUTING.md) and its
[LICENSING.md](https://github.com/HQChat/HQCHAT/blob/main/LICENSING.md) before
you start. A contribution to the Apple apps is accepted only with the grant
LICENSING.md describes.

The house style applies everywhere:

- **Comments are functional documentation.** Say what code provides, and why
  only where the code cannot. Never narrate history.
- **Commit messages are prose.** Say what changed and why it needed to.
- **No dead code.** If something is retired, delete it.
- **Everything is public**, history included. No keys, no personal addresses,
  no origin IPs.

Do not open a public issue for a vulnerability. See [SECURITY.md](SECURITY.md).
